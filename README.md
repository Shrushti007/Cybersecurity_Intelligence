# Cybersecurity Intelligence Dashboard | Power BI

An interactive Power BI dashboard designed to analyze cybersecurity threats, monitor security incidents, and provide actionable insights into an organization's security posture. The dashboard transforms cybersecurity data into meaningful visualizations to help identify attack patterns, track incident trends, and support data-driven security decisions.

### Key Features
- Cybersecurity incident monitoring and threat analysis
- Attack type and attack source analysis
- Department-wise incident tracking
- Incident trend analysis over time
- KPI cards for security monitoring
- Interactive filters and drill-down analysis
- Multi-page dashboard with navigation between overview, incident analysis, and incident log pages

### Tech Stack
- **Power BI** – Dashboard development and visualization
- **DAX** – KPI calculations and analytical measures
- **Power Query** – Data cleaning and transformation
- **CSV** – Data source

### Project Objective
To develop an interactive cybersecurity intelligence solution that helps security teams understand threat patterns, monitor incidents, identify high-risk areas, and improve incident response through data visualization and business intelligence.
